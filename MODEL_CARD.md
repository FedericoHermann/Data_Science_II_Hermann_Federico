# Model Card

## Uso previsto
Demostración educativa de un pipeline de clasificación binaria reproducible.

## No usar para
Diagnóstico, decisiones clínicas o atención sanitaria.

## Datos
Breast Cancer Wisconsin de scikit-learn.

## Métricas
ROC-AUC principal; PR-AUC, recall, precision, F1 y costo ponderado como apoyo.

## Riesgos
Tamaño moderado, ausencia de validación externa y posible falta de representatividad para nuevas poblaciones.
